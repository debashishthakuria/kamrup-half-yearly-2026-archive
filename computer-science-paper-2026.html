Section 1 · Short answers

1 mark each · 4 questions

Question 1(a)

What is a database?

Suggested answerA database is an organised collection of related data, stored so that it can be accessed and managed efficiently.

Question 1(b)

What is a field?

Suggested answerA field (attribute/column) is a named property of a record in a table, such as Roll_No or Name.

Question 1(c)

State the use of break statement in a switch-case statement.

Suggested answerbreak ends the current switch statement and transfers control to the statement after it; it prevents execution from falling through to subsequent cases.

Question 1(d)

What is a character constant in C++?

Suggested answerA character constant represents one character, written in single quotes, such as 'A' or '7'. Double-quoted "A" is a string literal.

Section 2 · Explain briefly

2 marks each · 8 questions

Question 2(a)

Write the differences between DML and DDL.

Suggested answerDDL (Data Definition Language) creates or changes database structure: CREATE TABLE, ALTER TABLE, DROP TABLE. DML (Data Manipulation Language) changes stored rows: INSERT, UPDATE, DELETE. Some curricula group SELECT under DML, while others call it DQL.

Question 2(b)

Write the use of the %= operator with an example.

Suggested answer%= is remainder-assignment for integer operands. x %= y means x = x % y. For int x = 17; x %= 5;, x becomes 2.

Question 2(c)

Rewrite the following statement using an if-else statement: x = ((y < z) ? y : z);

Suggested answer
if (y < z)
    x = y;
else
    x = z;
Both forms assign the smaller of y and z to x (and z when they are equal).

Question 2(d)

What is meant by testing and debugging in a program?

Suggested answerTesting runs a program on chosen inputs and compares actual with expected results. Debugging locates the cause of a fault and fixes it, then retests the program.

Question 2(e)

Differentiate between while and do-while loop.

Suggested answerwhile checks the condition before the body and may execute zero times. do-while checks afterward and executes its body at least once. A do-while statement ends with a semicolon.

Question 2(f)

What is a flowchart? Give one example.

Suggested answerA flowchart is a diagram representing an algorithm with standard symbols and arrows. Example: Start → input n → decision n % 2 == 0? → print “even” if yes, otherwise “odd” → End.

Question 2(g)

Differentiate between i++ and ++i.

Suggested answerBoth increase i by 1. i++ (post-increment) yields the old value in an expression, then increments. ++i (pre-increment) increments first, then yields the new value. With i = 4, a = i++ sets a = 4; starting again at i = 4, a = ++i sets a = 5.

Question 2(h)

What is operator in C++? Explain briefly.

Suggested answerAn operator is a symbol that performs an operation on one or more operands. Examples: + adds values (3 + 2 is 5); == compares for equality; && combines boolean conditions.

Section 3 · Extended answers

5 marks each · answer any six of eight in the exam

Question 3(a)

Define data type. What are the different data types used in C++?

Suggested answerA data type specifies the kind of value a variable may store and the operations allowed. Fundamental types include int (whole numbers), char (characters), float and double (real numbers), bool (true/false) and void (no value). Derived types include arrays and pointers; user-defined types include classes and enumerations. Example: int age = 17; char grade = 'A'; float price = 12.5;

Question 3(b)

What is constructor? Explain with an example.

Suggested answerA constructor is a class member with the same name as its class and no return type, automatically called when an object is created. It commonly initialises members. In this Turbo C++ example, Student s(12) calls the constructor to set roll to 12.
#include <iostream.h>
#include <conio.h>

class Student
{
    int roll;
public:
    Student(int r)
    {
        roll = r;
    }
    void show()
    {
        cout << "Roll number: " << roll;
    }
};

void main()
{
    clrscr();
    Student s(12);
    s.show();
    getch();
}

Question 3(c)

Explain the different types of errors in programming.

Suggested answer
  • Syntax / compile-time error: breaks a language rule, such as omitting a semicolon; the compiler reports it.
  • Runtime error: occurs when the program executes, such as an invalid operation or accessing invalid memory.
  • Logical error: the program runs but gives an incorrect result, such as using addition instead of multiplication.
Testing with known inputs and debugging help find and correct these errors.

Question 3(d)

Write a program in C++ to display all prime numbers within a given range.

Suggested answerThe program reads two limits and inspects each integer in the inclusive interval. It skips numbers below 2 and looks for a divisor; a value with no such divisor is printed. It also swaps reversed endpoints. Example: input 10 20 prints 11 13 17 19.
#include <iostream.h>
#include <conio.h>

void main()
{
    int first, last, n, divisor, prime, temp;
    clrscr();
    cout << "Enter the start and end of the range: ";
    cin >> first >> last;
    if (first > last)
    {
        temp = first;
        first = last;
        last = temp;
    }
    cout << "Prime numbers: ";
    for (n = first; n <= last; n++)
    {
        if (n < 2)
            continue;
        prime = 1;
        for (divisor = 2; divisor <= n / divisor; divisor++)
        {
            if (n % divisor == 0)
            {
                prime = 0;
                break;
            }
        }
        if (prime == 1)
            cout << n << " ";
    }
    getch();
}

Question 3(e)

What is a variable? Why is a variable called symbolic variable? What is meant by dynamic initialization of a variable? Give example.

Suggested answerA variable is a named storage location whose value can change. It is symbolic because its meaningful name represents the location and value instead of requiring a raw address. Dynamic initialisation gives a variable its initial value from an expression evaluated at run time: int a, b; cin >> a >> b; int sum = a + b;. Here sum depends on the input.

Question 3(f)

What is the role of comments and indentation in a program?

Suggested answerComments document purpose, assumptions and non-obvious decisions; the compiler ignores them. C++ uses // for a line and /* ... */ for a block. Indentation visually groups code inside blocks, making loops and conditions easier to read, maintain and debug. It does not itself change the meaning of properly braced C++ code. Example: indent the body of an if inside its braces, and comment why a special case such as n < 2 is excluded in a prime test.

Question 3(g)

What are data types in MySQL? Name some common data types and their uses.

Suggested answerA data type specifies what kind of value a table column can hold. Examples: INT stores whole numbers (quantity); DECIMAL(6,2) stores exact decimal values (price); CHAR(n) stores fixed-length text (a fixed code); VARCHAR(n) stores variable-length text (a name); DATE stores a calendar date; TIME stores a time. MySQL also has DATETIME for date and time.

Question 3(h)

What is Typecasting? Mention the use of sizeof operator.

Suggested answerTypecasting explicitly converts a value to another data type. For example, float result = (float)5 / 2; gives 2.5 rather than the integer-division result 2. sizeof tells the size in bytes of an object or data type, e.g. sizeof(int) or sizeof(result). The number of bytes for int can vary by compiler; do not assume a modern compiler and Turbo C++ report the same number.
